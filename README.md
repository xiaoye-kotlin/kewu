# 课悟 · Kewu

> 基于华为云的多端协同 AI 课堂增效系统 · 参加华为 ICT 创新赛赛题 1

课悟想解决一个很朴素的问题：课堂里老师讲得快、学生记不住、课后复习没重点。我们把华为云的 AI 能力和多端协同揉在一起，让课堂内容被自动结构化、被智能重组，最后变成每个学生手里“懂自己”的学习助手。

<br>

## 它到底是干嘛的

简单说，课悟是一套跑在课堂场景里的协同系统。老师端一键开启，系统就会把讲课过程（语音、板书、屏幕）实时转写、提炼重点；学生端在大屏、手机、平板之间无缝切换，看到的永远是同一份同步状态。课后，AI 会把零散的课堂片段重新组织成带图谱的复习资料，而不是一堆没头没尾的录音。

核心就三件事：**实时协同、AI 结构化、多端一致**。

<br>

## 核心功能

课堂上真正用得上的能力，我们把它们做成了顺手的体验，而不是堆参数。

- **实时协同批注** — 老师和学生在同一块画布上同步标记，延迟低到几乎没有感觉。
- **AI 课堂纪要** — 语音转写 + 语义提炼，下课即出结构化的知识点清单。
- **智能复习卡片** — 课后自动把内容重组成记忆卡片和知识图谱，按遗忘曲线提醒。
- **多端一致体验** — 大屏、手机、平板共用一份状态，切换设备不丢上下文。
- **流畅动画贯穿始终** — 从页面转场到卡片翻面，动效是体验的一部分，不是装饰。我们用 Material 3 的缓动与层次把每一帧都打磨得顺滑。

## 技术栈

后端与云能力扎根华为云，前端用 Kotlin Multiplatform 一套代码多端落地。

- **华为云 CodeArts** — 项目协作、流水线、DevOps 全流程
- **华为云 RDS** — 课堂数据、用户关系的持久化存储
- **华为云 Redis** — 协同会话的实时状态与缓存层
- **Kotlin Multiplatform (KMP)** — 一套业务逻辑，Android / 桌面 / 前端共享
- **Compose Multiplatform** — 统一 UI，Material 3 设计语言贯穿
- **WebSocket** — 多端实时同步的通信底座

## 怎么跑起来

前置：Node.js（用于 Claude Code 等工具链）、JDK 17+、Android Studio / IntelliJ IDEA。

```bash
# 1. 克隆仓库
git clone https://github.com/xiaoye-kotlin/kewu.git
cd kewu

# 2. 用 IDEA / Android Studio 打开，等待 KMP 依赖同步

# 3. 配置华为云密钥（本地 .env，不要提交）
#    HW_ACCESS_KEY=xxx
#    HW_SECRET_KEY=xxx
#    RDS_URL / REDIS_URL 见团队内部文档

# 4. 启动桌面端验证
./gradlew :desktop:run
```

后端服务与云资源由队友 A 在 CodeArts 上统一编排，本地联调文档放在 `docs/` 里。
